# 合成数据博客问答验证

现有账号与真实博客验证请使用[站点验证入口](../../docs/development/blog-qa.md)；本目录保留合成控制回归。

独立 FastAPI 应用只监听 `127.0.0.1:8011`，供本地 Web `http://127.0.0.1:3031` 验证登录、真实模型工具调用和引用链路。它不导入生产应用、不连接生产数据库，不作为部署入口。

预置两名合成开发用户，仅存在于本应用。登录发放随机 HttpOnly Cookie；退出撤销该用户活跃运行。文章来自 `dataset.py` 的三篇合成公开文章，点击来源打开本地原文，不链接或冒充线上文章。模型调用由独立 `model_proxy.py` 负责；运行环境未就绪时能力关闭，不使用模拟回答兜底。

## 启动与限制

在仓库根目录运行：

```sh
corepack pnpm dev:blog-qa:fixtures
```

打开 [本地博客问答](http://127.0.0.1:3031/aigc/blog-qa)，点击「使用本地测试账号」，选择示例问题或输入「博客问答怎样核对参考来源？」后提问。回答完成后点参考文章查看原文，刷新页面可恢复同账号最近一次运行。模型为真实 `qwen38_27b`，使用仓库已登记的 keyless 地址，不需要导入任何生产凭据；远端模型不可用时明确失败，不模拟回答。

启动需要仓库指定 Node/Corepack、已有 `apps/api/.venv`、macOS sandbox-exec，以及下载锁定 DSH 包和访问模型端点的网络。3031、8011 需空闲，端口冲突会退出，不停止其他项目。按 Ctrl+C 一并停止前端、后端与 Worker，临时 SDK 环境删除；SQLite 账本保留以测试恢复。开发账号会话不落盘，重启后需重新点击登录。

可按顺序核对：

1. **正常问答**：答案来自合成文章，参考链接打开本地原文。
2. **无结果**：提问「量子纠缠实验的结论是什么？」；没有相关文章时固定回答「未找到相关公开文章」。
3. **取消**：开始新问题，在「正在搜索和读取文章」时点击停止，状态为已取消，迟到结果不能覆盖。
4. **刷新**：已完成后刷新，回答与来源恢复；退出测试账号后旧回答清除。
5. **重启**：运行中停止启动命令，再次启动；重新登录后最近运行显示中断，不重放模型调用。

launcher 在每次启动时准备 Worker 依赖、沙盒和模型代理。手动使用 API venv 启动时，需要 `PYTHONPATH` 包含 `apps/api` 和本目录；入口为 `server.py`，端口固定为 8011。

默认 Worker 仅支持 macOS `sandbox-exec`，使用 launcher 提供的 `DSH_LOCAL_WORKER_DIR` 临时工作区与 `DSH_LOCAL_NODE` 绝对路径。缺沙盒不降级裸跑。此结果不能证明 Linux 文件/网络隔离已验收。

SQLite 开发账本位于 `.tmp/dsh-blog-local/ledger.sqlite3`，保存运行、工具调用、来源摘要和交付回执，不保存会话凭据。服务重启后已有未完成运行标为 `interrupted`，不会自动重放。全站并发 1、每次运行 45 秒、模型请求最多 4 次、工具最多 4 次、工具结果累计最多 64 KiB。超时、取消或流连接断开先终止账本状态再回收进程组；正常结束也清理残留进程。Worker 每次工作目录固定为临时 Worker 目录下的 `tmp/run-{run_id}`，API 在进程退出后删除并短暂重试残留目录。

工具调用需要 Worker 服务凭据与运行凭据同时有效。只暴露搜索和读取公开文章两项工具，每次调用、模型请求和完成前重新检查会话与运行状态。读取来源先保存，收到匹配摘要回执后才可引用；完成时重读文章摘要，历史查询中变更或删除的来源隐藏链接。完成结果必须匹配运行的根会话，答案按纯文本交付，拒绝模型返回的 URL、HTML 或 Markdown 链接，来源链接由服务端生成；空搜索使用固定“未找到相关公开文章”。

## 验证

```sh
apps/api/.venv/bin/python -m unittest discover -s apps/api/tests -p test_blog_qa_local.py
```

自动测试使用注入 runner 验证控制与拒绝路径，不调用真实模型，不以此证明模型回答质量。真实模型端到端结果由本次运行的单独验证记录给出。

本地账本、开发用户与单进程并发限制不替代计划中的 MySQL 运行账本、Redis 准入、真实账户授权、Linux Worker 隔离或生产内测验收；A–D 的剩余门槛仍需按实施计划完成。
