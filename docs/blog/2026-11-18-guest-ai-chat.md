# 游客聊天接入 GPT-6.1 Sol

**游客可以直接使用 GPT-6.1 Sol**。输入框旁可以选择低、中、高三档思考程度，默认中档。本次更新已在本地验证。

## 一、游客如何使用 {#guest-chat}

打开 AI 聊天页，输入问题即可。服务器使用站点配置的 OpenAI 凭据，并限制游客请求只能使用 GPT-6.1 Sol。游客会话仍使用临时上下文，登录后可使用账号的模型配置及保存的对话。

## 二、聊天页的变化 {#chat-layout}

顶部移除了聊天与工作的切换栏。短问题在右侧以贴合内容的气泡显示，回复在左侧展开。消息列表与输入框各自占位，长回复可以在消息区内滚动阅读。

游客的模型名和当前思考档位显示在同一个文本按钮里。点开后可用左右方向键或触屏切换低、中、高三档。点击面板里的模型名可进入模型列表，并可返回调节思考程度。登录后，模型入口会列出账号可用的站点模型和个人配置，所选模型用于下一次发送。

输入文字或进入已有对话后，输入区在上，模型、附件、语音和发送等控件在下。菜单会根据屏幕边缘的可用空间调整位置。

发送后，回复位置会显示「正在思考」和已等待的秒数。收到首段正文后便开始流式显示，生成结束后出现复制、重新生成等操作。消息和操作区采用淡入过渡，系统开启「减少动态效果」时会关闭这些过渡和等待动画。

搜索、附件、语音和回复操作等图标在悬浮或获得键盘焦点时会显示提示。未输入消息时，把指针移到发送按钮上可以看到禁用原因。

生成完成后，操作按钮旁依次显示 **本次耗时和 token 总量**。复制成功后，复制图标变为勾号。把指针停在 token 总量上，或用 Tab 聚焦它，可看输入和输出明细。耗时由服务端计时，token 数取自服务商回执。服务商省略用量时，页面只显示耗时。这些数据随实时回复显示，保存在当前页面会话中。

把指针停在消息正文上，或用 Tab 聚焦正文，即可查看发送时间或回复完成时间。时间按浏览器的本地时区显示，精确到秒。
