# 在现有站点验证博客问答

## 启动

在仓库根目录运行：

```sh
corepack pnpm dev:blog-qa
```

打开 [普通 AI 页面](http://127.0.0.1:3030/aigc)，从左侧「博客问答」进入；也可直接打开[博客问答](http://127.0.0.1:3030/aigc/blog-qa)。未登录时点击「登录后提问」，使用现有账号的正常登录方式，成功后返回问答页。当前核验的本地登录配置只有密码方式可用，QQ/短信等尚未配置本地凭据与回调；不要以此声称已完成这些方式的本地登录验收。不会创建合成账号，也不提供绕过站点登录的入口。

默认只读盘点当前配置数据库中启用的管理员账号，将其 ID 放入本次本地名单；每次操作仍检查该账号当前是否启用、是否仍有管理员角色。需要验证其他已有账号时，先在现有账号管理中查稳定 ID，再显式启动：

```sh
corepack pnpm dev:blog-qa --user-ids 目标账号ID
```

多账号用英文逗号分隔。显式 ID 名单只授予本地只读问答准入，不改变数据库角色或发布权限。未登录、名单外、被禁用或已撤销会话均拒绝运行。界面不会请求用户提供密码给开发助手。

## 使用真实数据与现有流程

- Web 使用正常同源 `/api` 代理；API 为正常 FastAPI 应用，复用现有 `AuthManager`、Redis 会话、用户/角色查询、MySQL 博客元数据和 MongoDB 正文。
- 首次能力初始化默认从现有全局模型目录读取默认模型配置，不接受浏览器/模型指定服务地址，也不使用个人 Provider。服务运行期间固定配置，改默认模型后重启。
- 当前连接的旧目录缺少auth_mode/is_default，本地也未提供DeepSeek密文解密配置。仅做只读兼容：缺认证类型按bearer处理，缺默认标记时只允许唯一启用模型成为候选，不执行DDL或改写目录。为本机验收，已在受忽略的 `.tmp/dsh-blog-site/options.json` 显式选择 `qwen-public`，页面标为本地测试模型。也可用 `--model qwen-public`；只允许这一固定测试模型，生产拒绝覆盖。补齐默认模型所需配置后移除本地options的model选项，即恢复目录选择。
- 搜索和读取调用与博客 HTTP 共用的公开查询服务，缺正文/已删除文章不可读；引用由应用生成 `/blog/{id}`，打开正常博客详情页。
- 站点现有登录页、账号中心、博客浏览、普通 AI 对话继续使用原接口；问答只读，不改文章。登录可能按原站点规则创建/轮换 Redis 会话，这是正常登录行为。
- 本地运行记录单独保存在受忽略的 `.tmp/dsh-blog-site/ledger.sqlite3`，文件权限0600；不创建或改动现有业务数据库表。请求身份仅保存在有界短期服务内存，不进入 Worker、模型或账本。

服务默认监听 Web `127.0.0.1:3030`、API `127.0.0.1:8032`。8030 被其他预览占用时不停止该进程。本地配置通过原 `local.yml` 与受保护覆盖文件加载，不在日志打印凭据。已存在的 PostgreSQL checkpointer 不执行启动 setup DDL；没有所需既有表时应先处理原开发环境，不在此启动器中迁移。

本地 JWT 签名使用显式环境配置，或启动器生成的0600开发密钥文件 `.tmp/dsh-blog-site/dev-session-key`，后者仅用于本地站点并可跨重启保持 Cookie 可验证。该目录已被 Git 忽略，不提交密钥、账本或截图。删除开发密钥会使旧本地 Cookie 失效，需要重新登录。

## 建议验收

1. 从普通 AI 页面打开博客问答；未登录时走原登录页并保留返回地址。
2. 用名单内真实账号登录，询问「博客里的 dsh 问答怎样拦下伪造引用？」等公开文章相关问题。答案应附实际读取文章的链接；打开链接核对正文。
3. 问不存在的主题，确认不伪造来源；没有匹配文章时返回固定提示。
4. 运行中点击停止、退出账号或关闭流连接；后续工具和最终交付应拒绝，迟到答案不覆盖取消。
5. 已完成后刷新问答页，当前账号及同一会话 family 可恢复最近结果；不同账号或新会话不能读取旧会话记录。
6. 验证正常 token 刷新：服务端对已验证运行根据 Redis 当前同设备/family快照接续，再严格验证当前 access token。旧 Cookie 从 HTTP 直接重放仍被拒绝；退出、禁用或新 family 都不能接续。
7. Ctrl+C 停止本次启动的服务；运行、模型请求和独立 Worker 进程组会撤销并回收。再次启动不会重放未完成运行。

## 当前边界

仅允许显式启用的本地运行环境；生产模式始终拒绝启动问答运行。仍使用开发 SQLite 账本和 macOS 沙盒，不代表 MySQL 运行账本、生产调度、Linux/PID/地址隔离或正式内测矩阵已经完成。

每次运行45秒、模型请求最多4次、工具最多4次、结果累计64KiB、全站并发1，准入另使用独立 Redis 原子限流。Redis/账号/模型/Worker不可用时失败关闭。已经交付的公开文章文本无法收回；历史来源变更或删除后隐藏失效链接。

原三篇合成文章入口保留用于独立控制回归：`corepack pnpm dev:blog-qa:fixtures`，端口3031/8011，详见[合成验证说明](../../tools/dsh-blog-local/README.md)。不要把合成入口结果当作真实账号验收。
