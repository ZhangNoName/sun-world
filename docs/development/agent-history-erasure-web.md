# 博客问答页面删除历史

2026-11-18，从 `110ac9b` 的暂停交接恢复。页面复用[正式 API 历史删除](agent-history-erasure.md)和[站点会话接线](agent-formal-web.md)。

- 仅正式模式中通过当前会话取得的终态结果提供「删除此问答」。发送删除前确认具体问答，服务端继续校验账号、原会话族、运行状态和 Origin。站点 SQLite 和合成模式没有删除入口。
- 对当前运行使用无请求体的 `DELETE`。收到成功响应及明确的布尔确认后移除结果，并清理指向同一运行的会话存储。请求失败或返回无法确认时保留结果，允许用户重试同一删除。删除期间暂缓开始、刷新及取消操作，避免重复提交和互相覆盖。
- AuthStore 的 `sessionRevision` 变化与账号切换同样使当前问答上下文失效。重查能力与已保存运行时仍由 API 校验会话族。忽略旧会话的迟到响应以及删除前发出的旧运行响应。客户端中止请求后，已经发出的删除仍可能在服务端完成。
- 用传输、Hook 和页面测试验证显式确认、重试、模式与运行状态限制、旧响应隔离。仅对合成数据运行删除验证。现有开发站点、后端契约及正式部署范围保持原状。
